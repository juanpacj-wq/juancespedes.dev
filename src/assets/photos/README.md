# Photos

Drop the portrait here as `portrait.jpg` (or `.jpeg`, `.png`, `.webp`). No code changes are
needed: `Portrait.astro` picks it up, crops it to 4:5 and builds AVIF and WebP versions at
320, 480, 640 and 960 px. Until the file exists, a monogram placeholder is shown.

- Portrait: vertical 4:5, at least 1600 × 2000 px, neutral background, soft light.
- Keep originals out of the repository if they exceed a few megabytes; export a web-ready JPEG
  (quality around 85) instead.
