# Art

- `narcissus.jpg`: Caravaggio, _Narcissus_ (about 1597-1599), public domain. A 1200 px web copy
  of a high-resolution scan, with the empty top 8 % cropped so the figure fills the hero; the
  original stays out of the repository.
- `narcissus.txt`: the same painting as text, generated by `pnpm ascii`
  (`scripts/generate-ascii.mjs`). Committed, so a build never depends on the script. Run it again
  only after changing the image or the settings at the top of the script.

The home hero renders the text with `src/ui/art/AsciiArt.astro` and uses a tiny copy of the
image to color the characters when the light is on (ADR 0018).
