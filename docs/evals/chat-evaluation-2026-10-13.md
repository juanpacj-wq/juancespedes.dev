# Chat evaluation, 2026-10-13 (UTC)

First run of the "Ask me" evaluation set ([ADR 0017](../adr/0017-ask-me-chat.md)) against the real
model, with the production instructions and the corpus generated by the build.

- Provider and model: DeepSeek, `deepseek-flash`, thinking off.
- Result: **30 of 30 cases pass** (threshold 27).
- Cost: USD 0.0120 for the whole run, USD 0.0004 average per question (threshold 0.005).
- With the corpus already cached: USD 0.00023 per question on average. The first question of each language pays the full corpus once (about USD 0.003).
- Prompt cache: every question after the first one per language read the corpus from the cache (no misses).
- Latency: about 1.6 s per complete answer.

Costs use DeepSeek Flash peak prices from aggregators (USD 0.30 per million uncached input tokens, 0.006 cached, 1.20 output) and the token counts the API returned.
