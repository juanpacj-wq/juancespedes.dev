problem: Every billing cycle, dozens of PDF energy invoices from two counterparties with completely different formats had to be keyed in and checked by hand, then compared with the values stored in the corporate database. It was slow, error-prone and spread across four scripts that each did part of the job.
responsibilities:
  - Analyzed each counterparty's templates, including the reliquidation credit note.
  - Merged four earlier projects into an architecture with one package per company and the same internal structure.
  - Built the graphical interface and the packaging for business users without Python installed.
  - Wrote the regression suite and the pattern coverage audit.
constraints:
  - Non-technical business users with no Python on their machines.
  - Third-party PDFs with encoding glitches and templates that change without notice.
  - A real zero must be distinguishable from a concept the invoice does not include.
decisions:
  - title: One package per company with the same structure
    rationale: Each counterparty has its own extractor, processing and export, and the interface picks the engine at runtime. Supporting a new format means adding a package.
    alternatives:
      - A single extractor full of per-company conditionals
  - title: Extraction by page coordinates
    rationale: In the tabular format, text is rebuilt by grouping lines by their vertical position, which keeps together the columns that a flat extraction mixes up.
    alternatives:
      - Extract plain text and split it with regular expressions only
  - title: A regression corpus before touching any pattern
    rationale: 73 real invoices frozen in a snapshot make the suite fail on any value change, and the snapshot is only regenerated after a manual check.
    alternatives:
      - Test with a handful of sample invoices
  - title: Fields that were not extracted are data too
    rationale: Every invoice carries the list of concepts its template did not include. When a new template arrives, the Excel file shows it in that list, and missing concepts never appear as zeros.
    alternatives:
      - Fill anything not found with zero
